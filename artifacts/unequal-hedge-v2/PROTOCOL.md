# 独立不等量对冲 V2 冻结协议

用户授权下一版直接实现、验证、部署。新目录前向 168 小时；不改 V1 冻结源、账本、亏损或通知游标。V2 本金/币种/倍数/费用沿用 V1：每组 20k、BTC/ETH 现货各约2k，倍数1/1.25/1.5/2/3为目标上限，1x是共同等量买入持有基准。不是同起点的V1/V2收益比赛；只能先比较V2内部相对1x增益，不能直接拿不同起点累计收益宣称改进成功。

## 固定研究假设（未拟合旧亏损窗口）

公共接口取300根5分钟K线；只用确认完整柱，按UTC三根连续5m聚合15m，缺口不补，不缩窗口。15m最近65根用于信号，至少64根。最新已完成5m柱的结束时刻距当前最多450秒（一个5m周期加150秒发布宽限）；不套用1m柱年龄，成交盘口仍限5秒。

- 大周期允许偏空：15m收盘 < SMA20 < SMA60，SMA20比三根前下降。
- 入场时机：该大周期条件满足，5m收盘从SMA20上方穿回下方；预测资金费为正、下一结算仍在未来。缺少回抽交叉不追空。
- 普通趋势退出：连续两根完整15m柱，收盘均高于SMA20且SMA20上升；一次5m反弹不立即退出。硬止损仍按每轮盘口触发，下一帧执行，不等待15m收盘。
- 一轮大周期只准一次额外入场。实际成交后armed=false；只有观察到连续两根完整15m不满足偏空趋势，才重新armed。冷却30min、每UTC日每币最多4次同时保留；午夜不重新武装。
- 费用门槛：当前可卖价至过去24根5m（不含信号柱）最低价的空间，须同时 >=2倍往返费用预算、>=1.5倍初始止损距离。预算含买卖盘口价差、双边taker费用、10bps压力滑点。计划时用最优档预筛，执行时按该倍数组真实数量的完整双向盘口VWAP重算。历史低点仅是结构性空间筛选，不作为预测利润入账，也不保证价格会到达。
- 初始止损=max(2×5m最近14根简单真实波幅平均,价格×0.2%)；保留原单笔40预算、1R成本保护、2R移动止损、6h最长持有、日增量亏损100/总400锁。成本不足就跳过，不为了入场缩窄止损。
- 等待结算标记K线等数据：禁止加仓、保留null缺口，但不把这一状态单独当成平仓触发。硬止损、价格行情缺口、真实风险预算仍可退出。修正V1短暂结算等待产生往返费用的问题。

## 工程与审计

固定Decimal ROUND_HALF_UP；审计按事件原顺序重放成交和资金费，同时核验资金费事件与去重表，避免把资金费统一挪到最后导致十进制尾差。原账本不迁移、不重写。V1保持原发布运行，V2源变更只在新不可变发布使用。

每组报告公开当前大周期/入场交叉与入场成本证据。V2独立通知服务与游标，消息显式标注V2，仍是公共行情模拟。历史盘口/采样缺口则正式收益比较null；不以诊断值挑赢家。原资金套利与V1进程不重启。
